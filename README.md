## Features

- **Ore ESP** — highlights every ore type through walls with its own color
- **Fast Mine** — removes pickaxe swing delay
- **Auto Mine** — automatically mines the nearest ore
- **Speed** — move faster than normal
- **Noclip** — walk through walls
- **Fullbright** — brightens the entire map for visibility in caves

## Ore Colors

| Ore | Color |
|---|---|
| Coal | Dark Gray |
| Copper | Orange |
| Iron | Light Gray |
| Nickel | Silver |
| Zinc | Blue-Gray |
| Slate | Dark Blue |
| Rock | Gray |

## Usage

Copy the code below and paste it into your executor:

loadstring(game:HttpGet("https://raw.githubusercontent.com/Noxis-spec/lithos/main/loader.lua"))()

The loader will show a loading screen, then open the menu.

## Compatibility

Tested on:
- Arceus X Neo

Requires executor with hookmetamethod, getrawmetatable and getreg support.

## Menu Tabs

- **Mining** — Ore ESP, Fast Mine, Auto Mine
- **Misc** — Speed, Noclip, Fullbright
